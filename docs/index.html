THREE IDEAS THAT PREVENT CONFUSION

01 / PLAN

A program is reusable.
A service is one run.

Live adjustments don’t rewrite your saved plan or old reports.

02 / OUTPUT

Pause stops time.
Blank hides the screen.

A moving arc alone doesn’t prove the physical sign is current.

03 / PEOPLE

Synced is delivery.
Seen is a person.

Ask for explicit acknowledgement when an instruction needs it.
